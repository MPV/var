# Go port — task plan (TDD, conformance-gated)

- **Date:** 2026-07-09
- **Specs:** `2026-07-09-go-core-port-design.md`,
  `2026-07-09-go-runner-testing-design.md`
- **ADRs:** [0006](../../adr/0006-go-port.md), [0007](../../adr/0007-go-testing-integration.md)
- **Execution:** one module at a time — translate the reference unit
  test/golden, watch it fail, port the module, gate on conformance, commit one
  green increment. Run with `superpowers:executing-plans` /
  `subagent-driven-development`.

Each task ends green: `go test ./...`, `go vet ./...`, `gofmt -l` empty.
Commit scope `feat(go/...)`; shared-corpus additions `feat(spec): ...`.
